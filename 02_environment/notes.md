# 02｜实验环境与可复现

## 核心概念

记录操作系统、Python、依赖、设备、随机种子和命令，才能复现结果。显存约束批量与上下文，磁盘决定数据与检查点能否保存。

## 观察一个例子

同一脚本在不同随机种子下得到不同初始权重。先固定数据、配置和种子，运行两次并记录输出；再只改种子。若两次结果不同，就能区分随机初始化的影响与代码变更的影响。

## 技术细节与实践流程

### 技术机制

实验环境由 Python 解释器、依赖版本、操作系统、设备驱动与运行配置共同决定。正式 GPU 训练还要确认框架能识别 GPU，以及所选精度和算子受到支持。显存预算包含权重、梯度、优化器状态和激活；磁盘还需容纳语料分片、临时文件、检查点及评估输出。只按模型权重大小估算通常不够。

### 实践步骤

先在独立虚拟环境安装所需依赖，记录解释器路径和依赖版本，再用极小任务验证前向、反向与保存。保存启动命令、配置文件、数据哈希和随机种子。demo 输出 Python 与系统信息，是环境检查的第一步，并不会验证 CUDA、GPU 精度或训练性能。

### 检查与常见错误

相同种子不保证跨硬件、跨库版本逐位相同；还要控制随机状态、数据顺序及非确定性算子。环境验收应明确“命令能重跑”“指标接近”或“逐位一致”属于哪一级要求，不能混用。
