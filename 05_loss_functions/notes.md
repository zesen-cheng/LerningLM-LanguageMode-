# 05｜损失函数与任务

## 核心概念

回归预测连续值，分类预测类别概率；损失函数把预测与目标的差异压缩为可优化标量。语言模型通常使用下一个 token 的交叉熵。

## 观察一个例子

真值 token 概率越低，负对数损失越高。若正确 token 的概率从 0.1 提高到 0.8，负对数损失会由约 2.30 降到 0.22。这里衡量的是目标 token 概率，而不是回答是否有礼貌。

## 自问自答

**问：低损失是否等于安全、自然的聊天？**

答：不等于；还需独立的对话与行为评估。
