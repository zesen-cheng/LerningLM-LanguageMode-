# 05｜损失函数与任务

## 核心概念

回归预测连续值，分类预测类别概率；损失函数把预测与目标的差异压缩为可优化标量。语言模型通常使用下一个 token 的交叉熵。

## 观察一个例子

真值 token 概率越低，负对数损失越高。若正确 token 的概率从 0.1 提高到 0.8，负对数损失会由约 2.30 降到 0.22。这里衡量的是目标 token 概率，而不是回答是否有礼貌。

## 技术细节与实践流程

### 技术机制

语言模型交叉熵衡量真实下一个 token 的负对数概率。若真实概率为 0.8，损失约为 0.223；若为 0.05，损失约为 2.996。对多个有效位置取平均时，分母应是实际参与监督的位置数。padding 和 SFT 中不参与监督的位置应排除，不能用它们把平均损失稀释。

### 实践步骤

demo 比较两种真实 token 概率对应的损失。正式训练常将 `[B,T,V]` 的 logits 展平为 `[B*T,V]`，标签展平为 `[B*T]`，其中 B 是批大小、T 是长度、V 是词表大小。PyTorch 的交叉熵接收原始 logits，通常不用先做 softmax；接口细节见 [CrossEntropyLoss 文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.CrossEntropyLoss.html)。

### 检查与常见错误

先 softmax 再把结果当 logits 输入交叉熵，会改变实际计算。还要检查标签是否越界、输入和目标是否错位、有效标签是否为零。训练 loss 与验证 loss 必须采用一致的归一化口径，才适合直接比较。

答：不等于；还需独立的对话与行为评估。
