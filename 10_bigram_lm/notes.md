# 10｜Bigram 语言模型

## 核心概念

bigram 只依据前一个 token 预测下一个 token，是理解条件概率的最小模型。它无法利用较远上下文。

## 观察一个例子

“北京是中国的”需要更长历史才能稳定预测后续。若只看到上一个 token“的”，bigram 很难判断后面是“天气”还是“首都”；若能读到更早的“北京是中国”，选择“首都”就有更多依据。

## 技术细节与实践流程

### 技术机制

bigram 用 `P(b|a)=count(a,b)/sum_b count(a,b)` 估计下一 token 概率。它只看当前一个 token，历史再长也不会改变同一个 a 对应的分布。没有见过的组合会得到零概率，计算对数损失时需要平滑；例如给每个候选计数加 α，再把分母加上 α 乘词表大小。

### 实践步骤

demo 用中文字符统计相邻转移，检查“苹”后出现“果”的次数。把“苹果”和“梨”比例改变，观察分布变化；再准备训练中没有出现的句子，用平滑后的概率计算损失。可以把计数表与神经网络的可学习转移 logits 对比，为后面的参数训练做准备。

### 检查与常见错误

训练前应固定词表与未知 token 策略，不能为了评估新句子临时扩词表却不报告变化。bigram 可以产生流畅的局部搭配，却无法稳定遵守远处的主体或约束，这正是它与长上下文模型的关键差别。

## 自问自答

**问：bigram 与 GPT 的共同目标？**

答：都可训练下一个 token 预测，但可利用的历史范围与结构不同。
