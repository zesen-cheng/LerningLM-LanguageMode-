# 11｜因果 Attention

## 核心概念

自注意力让当前位置按相关性读取前文。因果掩码禁止训练时偷看未来；Q、K、V 是查询、键、值的线性投影。

## 观察一个例子

生成第五个 token 时只允许读前四个及当前位置已有输入。输入“今天 下雨 所以 带伞”时，“带伞”的位置可关注“下雨”。训练时在“下雨”位置加上因果掩码，验证它看不到尚未出现的“带伞”。

## 技术细节与实践流程

### 技术机制

输入 X 经投影得到 Q、K、V，单头注意力可写成 `softmax(QK^T/sqrt(d_head)+mask)V`。因果 mask 将未来位置的分数排除，当前位置只能看到自己与此前输入。按下一个 token 目标训练时，这不会泄漏标签，因为本位置标签是尚未输入的后续 token。多头机制让不同投影关注不同线索。

### 实践步骤

demo 对三个位置逐次截取可见前缀。将最后一个值改得很大，检查第一个位置的结果仍不受影响，这是因果性的直观检查。真实实现还需核对 `[B,heads,T,d_head]` 的形状及 mask 方向。推理可缓存旧位置的 K/V，但需要正确更新位置索引，且必须与不缓存路径比较输出。

### 检查与常见错误

mask 方向弄反或输入目标未错位，会让训练结果异常乐观。KV cache 是推理复用机制，不是训练检查点；它通常随请求结束释放，也不负责跨会话永久记忆。启用缓存不应改变同一上下文下的模型含义。

## 自问自答

**问：这里的 K/V 与 KV cache 是什么关系？**

答：推理时可缓存历史 token 的 K/V 投影，避免每步重算。
