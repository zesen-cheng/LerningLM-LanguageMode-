# 11｜因果 Attention

## 核心概念

自注意力让当前位置按相关性读取前文。因果掩码禁止训练时偷看未来；Q、K、V 是查询、键、值的线性投影。

## 观察一个例子

生成第五个 token 时只允许读前四个及当前位置已有输入。输入“今天 下雨 所以 带伞”时，“带伞”的位置可关注“下雨”。训练时在“下雨”位置加上因果掩码，验证它看不到尚未出现的“带伞”。

## 自问自答

**问：这里的 K/V 与 KV cache 是什么关系？**

答：推理时可缓存历史 token 的 K/V 投影，避免每步重算。
