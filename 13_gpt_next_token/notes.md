# 13｜GPT 的下一个 token 目标

## 核心概念

GPT 型模型把前文映射到词表上每个候选 token 的分数。训练时用真实后续 token 计算损失；推理时根据概率选出下一个，再循环。

## 观察一个例子

“今天天气”之后的候选并非只有一个，模型给出一整个分布。给模型前缀“今天”，它可能给“晴”“下雨”等候选不同分数。训练时拿真实下一个 token 算损失；生成时选一个候选追加，再用更长前缀继续预测。

## 自问自答

**问：文本到训练经历哪些步骤？**

答：文本清洗→tokenizer→token ID→序列切块→模型前向→损失→反向更新。
