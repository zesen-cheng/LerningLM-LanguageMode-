# 13｜GPT 的下一个 token 目标

## 核心概念

GPT 型模型把前文映射到词表上每个候选 token 的分数。训练时用真实后续 token 计算损失；推理时根据概率选出下一个，再循环。

## 观察一个例子

“今天天气”之后的候选并非只有一个，模型给出一整个分布。给模型前缀“今天”，它可能给“晴”“下雨”等候选不同分数。训练时拿真实下一个 token 算损失；生成时选一个候选追加，再用更长前缀继续预测。

## 技术细节与实践流程

### 技术机制

语言模型末端把隐藏状态 `[B,T,D]` 映射成 `[B,T,V]` 的 logits。训练可并行计算所有已知输入位置，目标与输入相差一个 token；例如 `x=[A,B,C]`、`y=[B,C,D]`。因果 mask 保证每个位置仍只依赖前缀。推理则必须逐步选择新 token，追加到输入或缓存后继续计算。

### 实践步骤

先检查三对输入与目标是否分别为 A→B、B→C、C→D，再检查交叉熵的词表维度。demo 用固定转移表展示逐 token 追加，不会训练完整 GPT。把转移表换成概率分布后，就能进一步观察“模型输出候选分数”和“生成程序选一个候选”是两个步骤。

### 检查与常见错误

目标错移两次或完全没有错移都可能训练错误任务。有些模型接口内部会移动 labels，有些要求数据侧预先移动，必须读清实现，不能两边同时移。生成还需有 EOS、输出长度限制与上下文限制，否则程序可能不断续写。

## 自问自答

**问：文本到训练经历哪些步骤？**

答：文本清洗→tokenizer→token ID→序列切块→模型前向→损失→反向更新。
