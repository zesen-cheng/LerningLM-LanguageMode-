# 17｜训练与检验 tokenizer

## 核心概念

词表大小是可用 token ID 种类数，不是上下文长度。中文、英文、代码和数字都应做编码/解码、压缩率及异常切分测试。

## 观察一个例子

32K tokenizer 通常表示约 32768 个 token ID；一次可读多少 token 由模型上下文配置决定。用中文、英文、数字混合句各取十条，编码后再解码，检查是否还原。随后统计每类每百字需要多少 token；如果中文数字被切得异常碎，就回头查词表样本。

## 自问自答

**问：词表翻倍会自动让上下文翻倍吗？**

答：不会；两者是独立配置。
