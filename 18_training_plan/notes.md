# 18｜预训练实验设计

## 核心概念

先定模型参数量、词表、上下文、训练 token 预算、批大小和更新步数。计算实际每步 token 数并留验证与保存频率。

## 观察一个例子

batch=2、累积=8、长度=1024 时，每次更新约处理 16384 个位置。按 batch=2、梯度累积=8、长度=1024 计算，一次更新最多处理 16,384 个位置。若计划处理 2B 个位置，先估算更新步数，再扣除填充与不计损失的位置。

## 自问自答

**问：训练 token 与参数量是什么关系？**

答：前者是看到的数据量，后者是模型可学习数值个数。
