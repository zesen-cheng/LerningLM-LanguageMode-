# 27｜偏好数据与 DPO

## 核心概念

偏好样本含同一提示下的优选与劣选回答。DPO 用参考模型与当前模型的相对对数概率直接优化偏好，无须在线采样。

## 观察一个例子

优选回答满足限制，劣选回答遗漏限制；DPO 拉开它们的相对概率。同一问题准备两条回答：优选回答满足字数限制，劣选回答虽然流畅却超字数。DPO 比较两者相对概率；随后仍用未见过的限制题验证是否泛化。

## 技术细节与实践流程

### 技术机制

标准 DPO 为同一提示 x 准备优选 y+ 与劣选 y-，计算回答 token 的条件对数概率和。令 Δ 为当前模型对两回答的 log 概率差减去固定参考模型的相同差值，则损失为 `-log sigmoid(βΔ)`。优化相对偏好不保证优选回答的绝对概率总会上升；它也可能主要压低劣选回答。参考 [DPO 原论文](https://arxiv.org/abs/2305.18290)。

### 实践步骤

demo 把整个偏好差简化为一个可学习数值，不包含 tokenizer、完整策略或参考网络。真实偏好对需共享同一提示，并排除提示位置损失；检查优劣回答是否真的有可判定差异。固定参考模型，不让它接收更新，记录 β、回答长度和偏好标签来源，再用未见偏好题评估。

### 检查与常见错误

优劣标签颠倒、截断后两回答相同、单纯偏好更长答案都会污染信号。DPO 属于离线偏好优化，并不是本案例已完成的在线 RL；不能把教学演示的概率上升报告成真实模型收益。

## 自问自答

**问：DPO 是不是在线 RL？**

答：通常不是；它是基于离线偏好对的优化。
