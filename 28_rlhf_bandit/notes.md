# 28｜RLHF 与在线强化学习

## 核心概念

强化学习让策略根据奖励信号更新；RLHF 常涉及偏好建模与策略优化。奖励设计、采样成本和稳定性使它不适合作为每个小模型的必经阶段。

## 观察一个例子

让模型生成候选、评估候选、再调整策略，和固定 SFT 样本不同。设一个玩具环境给合规回答奖励 1、违规回答奖励 0。策略每轮生成候选并据奖励调整；若它学会只输出空话来拿分，说明奖励设计出了偏差。

## 技术细节与实践流程

### 技术机制

语言模型作为策略时，状态是已有上下文，动作是选下一个 token，奖励评价生成结果。策略梯度利用奖励或优势值调节生成动作的概率；常见在线流程包含采样、评分、更新和独立验收。RLHF 的反馈与人类偏好有关，使用可验证答案奖励的 RL 则不必依赖人工逐条打分。奖励可来自规则或模型，但二者都会有偏差。

### 实践步骤

demo 在两个动作上优化期望奖励，是原理练习，不是 PPO 或 GRPO。进入真实在线训练前，先核对奖励函数对正确、错误、空答和投机回答的评分；再检查采样成本与参考约束。PPO 常使用裁剪的策略更新，GRPO 类方法常比较同提示的一组候选；具体实现需要对应算法和配置，不能只沿用玩具更新。

### 检查与常见错误

奖励高不证明通用质量提高，还要看事实、长度、约束和旧任务回归。先有稳定 SFT 基线与可信评分，再考虑在线 RL。固定参考 KL 约束也可以用于 SFT 能力保留，它的存在本身不代表训练已成为强化学习。

## 自问自答

**问：奖励分升高等于模型全面变好吗？**

答：不等于；可能出现奖励投机，需要独立评估。
