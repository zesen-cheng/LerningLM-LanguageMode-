# 31｜HTTP/JSON 最小接口

## 核心概念

服务把请求解析为输入、调用推理并返回结构化 JSON。接口应限制输入长度、并发、超时与错误响应。

## 观察一个例子

POST /generate 接收 prompt 和 max_tokens，返回 text 与耗时。向本地接口发送包含 prompt 与 max_tokens 的 JSON，请求成功时返回文本与状态码。再分别发送空提示、过长提示，核对错误码与超时行为是否稳定。
