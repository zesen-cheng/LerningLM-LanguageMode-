# 37｜案例：设备、配置与目标

## 核心概念

本地案例目标是训练约 0.2B 参数的中文基础模型，再探索对话 SFT。先读真实配置和日志，不把课程示意数当成最终成绩。

## 观察一个例子

配置含词表 32768、上下文长度 1024，二者不是同一量。读本案例配置中的 vocab_size=32768 和 block_size=1024，分别写下“可用 ID 种类”和“单次序列长度”。再对照模型参数统计，避免把三个数字都叫规模。

## 自问自答

**问：参数量与训练 token 如何分开记录？**

答：参数量来自模型结构，训练 token 来自实际数据处理计数。
