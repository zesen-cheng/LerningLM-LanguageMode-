# 38｜案例：数据与 tokenizer

## 核心概念

本案例建立语料池、清洗/审计并训练 32K 词表。教学重点是来源可追溯、训练/验证隔离与 tokenizer 回编码测试，不把 2B token 自动称为高质量。

## 观察一个例子

按来源和类别记录保留率，比只报总量更能发现偏差。从原始语料抽出一份样本，记录来源与过滤原因；用新 tokenizer 编码、再解码，核对文本和 token 计数。随后检查训练与验证是否按文档隔离。

## 自问自答

**问：32K 指什么？**

答：约 32768 个 token ID 的词表规模。

在本目录运行 `python demo.py`。演示只用 Python 标准库；玩具实验用于解释机制，不代表真实 0.2B 模型成绩。
