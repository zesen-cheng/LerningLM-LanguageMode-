# 43｜结课：tokenizer 基线

## 核心概念

记录词表、特殊 token、未知片段处理、编码/解码一致性和各类文本压缩率。换 tokenizer 后不能直接沿用旧 embedding 权重。

## 观察一个例子

对中文、数字、英文混合样本分别计算每字 token 数。拿“今天 20°C，Python 3.12”做混合文本样本，查看特殊符号、数字与英文的 token 切分。训练前存下编码结果，换词表后重新比较长度与回编码。

## 自问自答

**问：为什么词表越大不一定越好？**

答：模型 embedding 更大，且切分质量需靠真实分布检验。
