# LearningModeLLM｜从零训练小语言模型

本课程从基础概念开始，走完数据准备、tokenizer、预训练、SFT/偏好优化、推理接口与项目复盘。48 课正文均在本目录独立编写；每课有 `notes.md` 和标准库离线 `demo.py`。六个主题的末尾都有“解答与复习时间”，包含问答、自测和达标要求。

为什么亲手训练一个小 GPT？因为我们希望理解回答背后的计算过程：文本如何编码、上下文如何参与预测、权重如何通过损失更新，以及数据与训练目标怎样影响最终行为。本地约 0.2B 模型让这些步骤可以被观察和复现，也让我们熟悉数据准备、资源预算、训练、暂停恢复、评估与后训练的完整流程。

先读[从零训练 0.2B GPT 的项目复盘](TRAINING_STORY.md)：文章用真实配置和结果解释技术流程，并讨论这次学习如何用于资料整理、多轮业务助手和自动化工作流。

**入口：**[逐课索引与可点击目录](course_plan.md)。建议按 00–47 顺序学习；遇到术语先读相应主题末尾的复习页，再运行本课演示。

## 学习顺序

- 00–14：AI、神经网络、token、Transformer 和 GPT。
- 15–22：语料、tokenizer、预训练、监控与基础评估。
- 23–29：SFT、封存评估、偏好优化、RLHF 原理与后训练验收。
- 30–36：推理服务、HTTP/JSON、流式协议、工具调用和网关。
- 37–41：本地 0.2B 项目复盘，只报告已有文件支持的结果。
- 42–47：学员自己的小模型结课实验。

## 怎样运行

每一课进入对应 `NN_英文主题` 目录：

```powershell
python demo.py
```

演示全部只用 Python 标准库，默认离线运行，不下载数据或模型，也不调用外部 API。部分课程用极小数字、模拟 HTTP 或玩具策略来解释机制；这些输出不等于真实大模型训练成绩。个别案例课程在本工作区可读取 `gpt02b_lab` 的报告；若单独复制课程目录，会改为显示“案例文件未找到”。

运行全部演示与结构测试：

```powershell
python verify_course.py
```

`lesson_content.py` 是课程正文的可维护源文件；`build_course.py` 从它和 `demo_templates.py` 生成逐课页面与代码。默认模式不覆盖手动编辑后的文件；确需重建时运行 `python build_course.py --force`。后续可逐课深化为 PyTorch/CUDA 实验，但本版先保证每课都有可运行、可解释的小演示。

## 学完后能带走什么

除了一个可观察的小模型，还能带走一套处理相似问题的方法：定义目标、组织输入与上下文、建立反馈、固定验收、记录状态和对比版本。所谓借鉴“GPT 的思维模式”，在这里指这些可迁移的建模与实验方法；它们可以帮助我们设计更清楚、可验证的工作流。

本案例完成了约 2B token 的基础预训练与多轮 SFT 实验，但通用聊天、事实准确性、算术和复杂约束仍未全面达标。原定 10B 有效语料池与部分严格质量门槛也没有完整证据。理解这些局限、能解释成功与失败的原因，是课程收获的一部分；具体结果见[项目复盘](TRAINING_STORY.md)和[实验数据摘要](case_evidence/experiment_summary.json)。
