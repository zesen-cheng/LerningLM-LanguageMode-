# 基础知识与 GPT｜解答与复习时间（25 分钟）

先独立回答 1–12 题，再看解释。把第 13 题写成一条完整的数据流，并运行第 08、12、13 课的 `demo.py`。

1. **token 是什么？tokenizer 又是什么？** token 是模型处理的离散文本单位，可能是字、词片段或标点；tokenizer 是把文本编码为 ID、再解码回文本的规则与词表。不要把 token 当作字符。
2. **tokenize 是什么？** 是按指定 tokenizer 把原始文本转成 token ID 序列的过程；预训练通常先做清洗、切分与编码，再保存或动态读取 ID。
3. **32K tokenizer 是什么？** 通常表示约 32,768 个可用 ID 的词表规模；它不是一次能输入 32K 个 token，也不是模型有 32K 参数。本项目配置为 `vocab_size=32768`。
4. **embedding 是什么？** 模型内部用可训练向量表示 token ID；ID 本身只负责索引，不含连续空间的语义距离。别和用来做检索的句子 embedding 混为一谈。
5. **训练集、参数量、训练 token、tokenizer 各指什么？** 训练集是样本集合；参数量是模型内可学习权重数；训练 token 是训练时实际处理的 token 位置数量；tokenizer 是文本与 ID 的转换器。一个数据集大小、模型参数量和上下文长度都不能互相替代。
6. **tokenizer 大小与上下文长度区别？** 前者决定 token ID 有多少种，后者决定一次前向可容纳多少位置。大的词表可能提高某些文本的切分效率，但增加 embedding/输出层资源；长上下文增加注意力/KV 等资源。两者独立配置。
7. **现在开源模型都多少 K？** 不存在统一数字，要查具体版本配置。例如 [Qwen3-0.6B-Base 的官方配置](https://huggingface.co/Qwen/Qwen3-0.6B-Base/blob/main/config.json)写 `vocab_size=151936`（约 152K）、`max_position_embeddings=32768`（32K 位置）；[Mistral-7B-v0.1 的官方配置](https://huggingface.co/mistralai/Mistral-7B-v0.1/blob/main/config.json)写 `vocab_size=32000`、`max_position_embeddings=32768`，但还设有 `sliding_window=4096`，说明仅看一个位置字段也不够。本案例是 32K 词表、1K 上下文。这里的 K 可能指词表、上下文或参数，必须看字段名；部署时实际可用上下文还受实现与显存限制。配置示例核对于 2026-09-27，并非全部开放模型的统计。
8. **权重、参数、激活有何区别？** 权重是训练更新并保存的参数；激活是特定输入前向计算产生的临时值。“0.2B 参数”约指 2 亿个可学习数值，不是 2 亿条训练文本。
9. **Transformer 是什么？** 一类使用注意力等模块处理序列的架构。GPT 常用因果解码器：当前位置不能读取未来 token；块内常有注意力、FFN、归一化和残差。
10. **Q、K、V 和 FFN 是什么？** Q/K/V 是注意力中用于匹配和读取的投影；FFN 是逐位置的前馈网络，负责非线性特征变换，不等于整个模型。
11. **GPT 如何生成一段话？** 模型据已有 ID 输出下一个 token 的分布，解码器选取一个 token，加入上下文后重复，直到停止条件触发。
12. **为什么 2B token 的预训练仍可能答不好“你好”？** 预训练优化续写概率，不必然学习用户/助手角色、结束标记、简短礼貌回复与多轮稳定性；还要检查数据与后训练。
13. **把整条链写出来。** 原始文本 → 来源/许可与清洗 → tokenizer 训练/选择 → tokenize 为 ID → 训练/验证切块 → token embedding 与位置 → GPT 前向预测 → 交叉熵 → 反向传播和权重更新 → 固定评估 → 采样生成。每个箭头都有可能引入质量损失。

## 自测与答案

- **题 A：** 词表 32K、上下文 1K、参数 0.2B、训练 2B token，哪一个决定一次最多输入多少 token？**答：**上下文 1K，且实际还要减去提示/生成占用。
- **题 B：** 换 tokenizer 后能原样加载旧 token embedding 吗？**答：**通常不能；ID 对应文本片段变了，必须处理映射或重新训练。
- **题 C：** 验证集损失下降是否证明多轮聊天稳定？**答：**不证明；需要独立的多轮封存评估。

达标：不用看答案也能解释词表、上下文、参数和训练 token 四个量，并能从 `config.json` 找出前两项。
