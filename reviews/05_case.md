# 真实案例｜解答与复习时间（20 分钟）

对照本项目真实文件，不用示意代码输出替代训练证据。

1. **这个案例的四个核心量是什么？** 目标模型约 0.2B 参数；配置词表 32768；配置上下文长度 1024；训练数据目标约 2B token。分别对应模型容量、编码种类、单次可见历史与样本量。
2. **2B 语料能自动证明高质量吗？** 不能。需要来源/许可、哈希、去重、分层审核、覆盖比例及训练/验证隔离的证据。
3. **CCI4.0 评分能自动决定纳入吗？** 不能。分类/质量分数是筛选信号，需观察分片分布和人工抽样校准。
4. **预训练 loss 下降证明了什么？** 证明当前目标与数据分布上的预测在改善；不直接证明多轮对话、事实性或安全性。
5. **为什么曾生成“大白、小白”等角色？** 可能是训练语料中的对话/剧本文本格式被模型当作续写模式，也可能与提示模板和解码有关；需要对照数据与固定生成测试验证原因。
6. **SFT 后为什么可能有回退？** 小模型容量、窄模板、学习率、样本重用与分布漂移都可能影响旧能力；应通过分项封存评估定位，不预设单一原因。
7. **案例数据如何成为课程证据？** 把配置、数据 manifest、训练日志、检查点、评估脚本和原始生成样例连接成可重跑链，明确观察与推断。
